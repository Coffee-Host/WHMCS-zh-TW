# WHMCS 前後台繁體中文語言包

本專案將 WHMCS 官方英文語言檔直接翻譯為台灣繁體中文（zh_TW），不以簡體中文譯文轉換。現行翻譯目標為 WHMCS 9.0.9。

## 英文來源與譯檔路徑

| 區域 | 英文來源 | 繁體中文譯檔 |
| --- | --- | --- |
| 後台 | `9.x/9.0.9/admin/lang/english.php` | `9.x/9.0.9/admin/lang/chinese.php` |
| 客戶端 | `9.x/9.0.9/lang/english.php` | `9.x/9.0.9/lang/overrides/chinese.php` |

## 安裝路徑

譯檔完成後，將對應檔案複製到 WHMCS 安裝目錄中的相同相對路徑。客戶端覆寫檔使用 `lang/overrides/` 目錄；後台譯檔放在 `admin/lang/` 目錄。若 `overrides` 目錄不存在，請先建立。安裝後可在語言設定中選擇 `Chinese`（語言檔名為 `chinese`）。

## 翻譯原則

譯文直接依照同版本 WHMCS 英文原始檔製作。PHP 結構、鍵名、註解及程式邏輯保持原樣，只翻譯字串值；模板佔位符、HTML/XML 實體、URL、電子郵件、數字、技術標記與品牌名稱均予保留。

目前此版本目錄只保留官方英文來源檔；繁體譯檔尚未建立，完成後會放在上表列出的路徑。

## 專案歷程

本專案先前沿用簡體中文專案的版本目錄與譯檔命名。自 WHMCS 9.0.9 起，翻譯方向改為直接由英文翻譯成台灣繁體中文，後台與客戶端使用各自指定的檔案路徑。
